💡 What: Pre-compiled static regex patterns (`ID_PATTERN` and `GITHUB_URL_PATTERN`) at the module level in `validate_report.py`.
🎯 Why: Calling `re.match()` with inline strings inside the `validate_report` loop unnecessarily triggers regex cache lookups and recompilation overhead for every item checked.
📊 Impact: Reduces per-item validation overhead. Although micro-seconds per item, the savings scale with the size of the JSON payload processed in tight loops.
🔬 Measurement: Profile the `validate_report` function with and without pre-compilation on large JSON payloads.
